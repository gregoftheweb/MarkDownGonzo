# Bundled fonts

MarkDownGonzo ships one regular (weight 400, Latin-subset) face of each font
below so the font pickers work without anything installed on the system.

| File | Family | License | Source |
|------|--------|---------|--------|
| `roboto.woff2` | Roboto | Apache-2.0 | Google Fonts |
| `roboto-mono.woff2` | Roboto Mono | Apache-2.0 | Google Fonts |
| `montserrat.woff2` | Montserrat | OFL-1.1 | Google Fonts |
| `baumans.woff2` | Baumans | OFL-1.1 | Google Fonts |
| `inter.woff2` | Inter | OFL-1.1 | rsms.me/inter |
| `geist.woff2` | Geist | OFL-1.1 | vercel/geist-font |
| `geist-mono.woff2` | Geist Mono | OFL-1.1 | vercel/geist-font |
| `jost.woff2` | Jost | OFL-1.1 | indestructible-type/Jost |
| `andika.woff2` | Andika | OFL-1.1 | SIL |
| `space-mono.woff2` | Space Mono | OFL-1.1 | Google Fonts |
| `cascadia-code.woff2` | Cascadia Code | OFL-1.1 | microsoft/cascadia-code |
| `opendyslexic.woff2` | OpenDyslexic | OFL-1.1 | antijingoist/opendyslexic |
| `opendyslexic-mono.woff2` | OpenDyslexic Mono | OFL-1.1 | antijingoist/open-dyslexic |

The woff2 files (except `opendyslexic-mono.woff2`) were taken from the
